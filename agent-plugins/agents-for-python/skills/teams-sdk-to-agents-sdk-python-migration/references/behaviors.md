# Behavior preservation by sample family

Use the union of pinned source behavior and the caller's parity requirements. Record each
behavior's source symbol, destination symbol, protected test, and manifest/setup impact.
An unresolved SDK gap needs exact evidence and options; omission is not parity.

## Cards

Preserve card-action and toggle-visibility commands, matching order, nested forms, initially
hidden elements and visibility IDs. Cover name submission, missing names, invoke status/body,
and fallback help advertising both commands. Align manifest titles and README surfaces.

## AI messages

Preserve AI labels, sensitivity and feedback metadata, and complete citation fields including
claim/source URL, keywords and card. Test overlapping keyword precedence. Feedback must retain
both reaction and feedback content. Unknown input returns stable help.

## Message extensions

Preserve Wikipedia command IDs, adaptive results, sanitized snippets, thumbnail previews and
empty/unknown-command responses. Unfurl the requested URL. Match supported link domains,
including en.wikipedia.org where configured. Preserve query/link response envelopes, compose
instructions, help and command contexts.

## Task modules

Preserve adaptive input, custom form and multi-step launch actions. Fetch must return the right
card or custom/fallback URL, and the server must actually serve the custom page. Carry the
name into the email step and preserve completion messages and submission envelopes. Describe
dialog actions accurately rather than presenting them as slash commands.

## Attachments

Retain downloaded bytes, names, sizes and consent context. Acknowledge acceptance before slow
upload, then continue proactively and send file info. Keep required upload headers and error
handling; clear pending data on decline/failure. Track background work for shutdown. Preserve
help, file manifest flags and configuration requirements.

## Meetings

Retain titles, timestamps, join actions and participant roles. Ignore agent-only participants
without AAD user IDs. Preserve Graph identifiers through typed conversion; cover missing
metadata and join-URL/resource fallback. Keep transcript delay/retry, newest selection, Graph
route, VTT parsing and unavailable fallback. Document subscriptions and reflect required RSC
permissions and webApplicationInfo in the manifest. Mock Graph transport without replacing
the real Teams SDK route wrappers.

## Targeted messages

Preserve mentioned reminder creation, private confirmation and delayed delivery to the captured
recipient/conversation. Scope lists and cancellation ownership to the user. Card cancel,
dismiss and snooze must acknowledge invokes and cancel timers. Suggested-action invokes share
text routing; help retains suggestions, AI labels and targeted prompt-preview metadata.

Reaction commands choose quoted-message ID, reply ID, then current-message ID. Preserve slash
restrictions, actual Teams transport, added-reaction acknowledgement and removal behavior.
Reject invalid/overflow times without scheduling. Separate application instances must not share
reminder state. Cancel background tasks on shutdown and document in-memory restart limitations.
