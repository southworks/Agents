# Agent AI Messages

This sample demonstrates AI message features for a Microsoft Teams agent using the Microsoft 365 Agents SDK.

- **AI labels** identify messages generated by AI.
- **Citations** provide source links, summaries, keywords, and an icon.
- **Feedback buttons** collect reactions and optional written feedback.
- **Sensitivity labels** communicate confidentiality guidance.

## Try the features

Send a message containing one of these keywords:

| Keyword | Result |
| --- | --- |
| `label` | Sends a message marked as AI-generated. |
| `sensitivity` | Sends a message with confidentiality guidance. |
| `feedback` | Sends a message with Teams feedback buttons. Submitted feedback is echoed by the agent. |
| `citation` | Sends an AI response with a numbered Microsoft Word citation. |

Matching is case-insensitive. If a message contains multiple keywords, the first match in the order shown above is used. Other messages receive usage guidance. These are message-text keywords, not slash or mention commands.

## Prerequisites

- Python 3.11 or later
- An Azure Bot resource with the Microsoft Teams channel enabled
- [Dev Tunnels CLI](https://learn.microsoft.com/azure/developer/dev-tunnels/get-started)

## Configure the agent

Copy `.env.TEMPLATE` to `.env` and set the client ID, client secret, and tenant ID for the Azure Bot connection. Do not commit `.env` or store production secrets in it.

For local Teams testing, expose port 3978 through a Dev Tunnel and configure the Azure Bot messaging endpoint as `https://<your-devtunnel-domain>/api/messages`.

The manifest in `manifest/` uses `${{AAD_APP_CLIENT_ID}}` for the Teams app and bot ID. Replace it with the Azure Bot's Entra app client ID before packaging. The manifest declares personal scope, matching the corresponding language samples.

To package the app, zip the contents of `manifest/` so `manifest.json`, `color.png`, and `outline.png` are at the archive root, then upload the package in Teams.

## Install and run

From this directory:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.main
```

The agent listens on `http://localhost:3978`. `GET /` reports readiness; message requests are authenticated at `POST /api/messages`.
